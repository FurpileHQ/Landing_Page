Furpile

A furry cuddle pile, online.

Coming in 2027

Furpile started as an idea for a geocities-style home for furries. Members would reserve their own subdomain, like yourname.furpile.org, and make a personal page there, within community guidelines.

We're still working out what Furpile will become. Options under consideration include a Bluesky server for the community, a shared file server, or the original subdomain-hosting idea. If you want to help shape it, we're open to collaborators.

Want to get involved? Get in touch and tell us what you'd like to build.
